# Codex Operating Guide

## Purpose

Build and improve the IT Study Notes site continuously while keeping a clear handoff trail between sessions.

## Session checklist

1. Read `ROADMAP.md` and pick the top unfinished item.
2. Read `ARCHITECTURE.md` and `CONTENT_GUIDE.md` before structural changes.
3. Implement one focused improvement at a time.
4. Update `ROADMAP.md` with progress and the next concrete task.

## If a session ends early

- Write the exact next action at the top of `ROADMAP.md`.
- Note any blockers (missing secrets, dependencies, or access).

## Quality bar

- Prefer static, free solutions.
- Keep build steps reproducible.
- Keep search and SEO working after changes.
