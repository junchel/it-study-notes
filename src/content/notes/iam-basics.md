## Summary

Identity and access management is the first line of defense in cloud and on-prem systems.

## Key ideas

- Grant least privilege and use role-based access.
- Separate human and service identities.
- Rotate secrets and audit access regularly.

## Commands or steps

```text
Checklist
- Define roles for teams
- Attach least-privilege policies
- Enable MFA
- Review access logs monthly
```

## Pitfalls

- Using shared accounts.
- Granting admin access by default.
- Storing access keys in repos.
