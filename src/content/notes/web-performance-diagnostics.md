## Summary

Performance work starts by measuring, not guessing.

## Key ideas

- Use RUM and synthetic tests to spot slow pages.
- Identify bottlenecks in network, server, or client.
- Fix the largest contributors first.

## Commands or steps

```text
Checklist
- Run Lighthouse or WebPageTest
- Review server response times
- Audit asset sizes and caching
```

## Pitfalls

- Optimizing micro-issues before big wins.
- Ignoring CDN and cache configuration.
- No baseline before changes.
